DSE Modbus Gateway

Connecting an ESP32-C3 to generator controllers through Modbus RTU over RS485.

Home / Projects / DSE Modbus Gateway

The problem

Industrial controllers expose useful operating information through protocols that need a hardware interface and careful interpretation. A gateway provides the bridge between a generator controller and software that can use those readings.

My role

I work on the embedded gateway and its development workflow, connecting ESP32-based firmware with DSE generator controllers. The public repository is the reference for the current implementation and setup instructions.

The engineering approach

The project uses an ESP32-C3 SuperMini with a MAX485 interface as a Modbus RTU master. Its primary target family includes DSE 7320 and 7320 MKII controllers. The documentation also covers Arduino bench environments to help separate electrical-interface issues from firmware behavior.

Decisions that matter

Register layouts, serial communication, and electrical signal levels need to be checked against the actual controller and interface. The repository separates getting-started guidance, a serial CLI reference, requirements, and phase status so that bench observations can guide the next change.

Explore the work

Read the repository for wiring guidance, build procedures, and diagnostics. This is an embedded communication project and a foundation for monitoring; the case study does not imply a deployed fleet or a completed cloud service.
